# Отчет по проекту

## 1. Перечень технологий, используемых для реализации варианта задания
Программный комплекс моделирования и оптимизации планировки помещений «Planeasier» разрабатывается с использованием следующего стека технологий:
* **Клиентская часть (Frontend):** TypeScript, React 19, Vite, Three.js, React-Three-Fiber, Drei, TailwindCSS 4, Zustand.
* **Серверная часть (Backend):** Python (FastAPI, Celery, SQLAlchemy), PHP, Uvicorn.
* **Машинное обучение (AI):** PyTorch.
* **Базы данных и хранилище:** PostgreSQL с расширением pgvector, Redis, MinIO (S3).

## 2. Обоснование выбора данных технологий и удобство их использования
* **React + Vite + TypeScript + Three.js:** Позволяют создавать интерактивные, высокопроизводительные 3D-сцены прямо в браузере с быстрой сборкой проекта и строгой типизацией.
* **Python (FastAPI) + PHP:** FastAPI обеспечивает высокую скорость и асинхронность, а скрипты на PHP используются для вспомогательной серверной логики.
* **PyTorch:** Главный инструмент для реализации заявленных функций нейросетевого анализа и генерации.
* **PostgreSQL + pgvector + Redis:** Обеспечивают надежное хранение реляционных данных, кэширование и эффективный косинусный поиск по векторным эмбеддингам 3D-моделей.

## 3. Декомпозиция системы и описание модулей
1. **Модуль параметрического 3D-моделирования (Core 3D Editor):** Отвечает за создание и редактирование 3D-геометрии комнат, генерацию этажей, расчет пересечений и булевы операции (CSG).
2. **Модуль Photo-to-3D (AI Scanner):** Отвечает за сегментацию, монокулярную оценку глубины, удаление шума и генерацию полупрозрачных макетов поверх загруженных фотографий.
3. **Модуль промышленно-складского проектирования:** Отвечает за алгоритмическую оптимизацию внутрискладских процессов (WMS), расчет маршрутов для техники и расстановку стеллажей на основе ABC-анализа.
4. **Генеративный ИИ-агент (Spatial AI Agent):** Модуль для автоматического анализа пропорций помещения, создания сценариев размещения объектов с расчетом эргономики, освещенности и формирования сметы.
5. **Базовый модуль платформы (Backend & Storage):** Управление пользователями, авторизация (JWT), сохранение проектов, обслуживание API и связь с S3 хранилищем.

## 4. Набор задач для реализации ПО, порядок выполнения и приоритеты
1. **Инициализация проекта и настройка окружения (Приоритет: Высокий).** Настройка репозитория Git, CI/CD, базового Docker-Compose.
2. **Проектирование и разработка БД (Приоритет: Высокий).** Развертывание PostgreSQL + pgvector, проектирование схем (users, projects, rooms, и др.).
3. **Разработка базового Backend API (Приоритет: Высокий).** Реализация авторизации, CRUD-операций для проектов.
4. **Разработка ядра 3D-редактора WebGL (Приоритет: Высокий).** Базовая отрисовка сцены, интерфейс для стен, окон, полов (React + Three.js).
5. **Разработка модуля Photo-to-3D и AI-агента (Приоритет: Средний).** Интеграция PyTorch, настройка инференс-моделей.
6. **Разработка модуля складской логистики (Приоритет: Средний).** Реализация WMS-алгоритмов расстановки стеллажей и расчета путей.
7. **Комплексное тестирование и оптимизация производительности (Приоритет: Средний).** Отладка, профилирование FPS в браузере, написание тестов.

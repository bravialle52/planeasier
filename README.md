# Planeasier

Программный комплекс моделирования и оптимизации планировки помещений «Planeasier». Предназначен для параметрического 3D-моделирования, автоматизированной планировки, генеративного ИИ-проектирования и логистической оптимизации жилых, коммерческих и складских пространств.

## Структура проекта
* `/frontend` — клиентская часть (React 19, Vite, Three.js, TypeScript).
* `/backend` — серверная часть (PHP).
* `/ai` — модули машинного обучения (PyTorch).
* `/devops` — конфигурации для развертывания (Docker, Docker-Compose).

## Запуск
Проект поддерживает развертывание с помощью Docker Compose.
```bash
docker-compose up --build
```
Подробности запуска каждого отдельного модуля смотрите в соответствующих директориях.
